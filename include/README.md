# include

## Overview

`include/` is the C header contract layer for the StreetVulkan engine, compiled with `-Iinclude` in `Makefile`. It defines the shared Vulkan engine state (`VulkanEngine`), vertex attributes, custom memory suballocator types, geospatial DEM terrain data, streaming sector and chunk metadata, road/traffic/vehicle/pedestrian simulation interfaces, camera/frustum math, HUD overlay and pause-menu inline utilities, ISO/IEC 25010:2023 telemetry, concurrent logging macros, and two vendored single-header C libraries (`cgltf.h` v1.15 and `stb_image.h` v2.30). This directory contains header files only and has no child subdirectories.

## Invariants

- **Binary & GPU ABI layouts**:
  - `[vulkan_types.h:PushConstants]` enforces `sizeof(PushConstants) <= 128` at compile time via `_Static_assert` (`mvp[16]` + `model[16]` = 128 bytes); `[vulkan_types.h:MAX_FRAMES_IN_FLIGHT]` (`2`) sizes all per-frame Vulkan arrays to avoid frame-in-flight data races.
  - `[vertex_format.h:Vertex]` defines a 52-byte (13-float) stride at binding `0` with `VK_VERTEX_INPUT_RATE_VERTEX` and locations `0..4` (`R32G32B32_SFLOAT`, `R32G32B32_SFLOAT`, `R32G32_SFLOAT`, `R32G32B32A32_SFLOAT`, `R32_SFLOAT`); `emission == 0.0f` represents matte geometry and `> 0.0f` emissive geometry.
  - `[car_system.h:CarInstanceData]` uses `#pragma pack(push, 1)` to guarantee an exact 96-byte instance stride (`model[16]`, `tint[4]`, `brake`, `pad[3]`); `[car_system.h:CarSystem]` uses `staticDummyBuffer` (`tint.a = 0`) at binding `1` when rendering static terrain geometry; `Car` fields obey `t` in `[0.0, 1.0]`, `direction` `0` (`a->b`) or `1` (`b->a`), `mesh_type` `0..5`, and `brake` `0.0` or `1.0`.
  - `[road_graph.h:RoadNode]`, `[road_graph.h:RoadEdge]`, and `[road_graph.h:RoadPoint]` use `#pragma pack(push, 1)` for exact binary RGP1 layout (20B, 28B, and 12B); `[road_graph.h:road_graph_build_debug_mesh]` offsets edges `+0.25m` on `Y` (green=two-way, blue=one-way, red=signalized node).
  - `[lighting_system.h:GpuLight]` and `[lighting_system.h:LightingUBO]` align vectors as `float[4]` groups for std140 UBO layout; `[lighting_system.h:MAX_GPU_LIGHTS]` is capped at `64` and `[lighting_system.h:MAX_STREETLIGHTS]` at `256`.
  - `[vulkan_memory_pool.h:VulkanMemoryPool]` stores up to `[vulkan_memory_pool.h:VK_POOL_MAX_BLOCKS]` (`128`) inline blocks and `[vulkan_memory_pool.h:VK_POOL_MAX_FREE_REGIONS]` (`256`) inline free regions before spilling to `extraFreeRegions`; `[vulkan_memory_pool.h:VulkanMemoryBlock]` maintains `mappedBase != NULL` iff the block is `HOST_VISIBLE`.
- **Coordinate spaces, math & DEM bounds**:
  - `[math_camera.h:Mat4]` is column-major (`col * 4 + row`); `[math_camera.h:mat4_perspective_vk]` inverts Y (`m[5] = -f`) and maps clip depth to Vulkan `[0, 1]`; `[math_camera.h:mat4_lookat]` and `[math_camera.h:camera_get_vectors]` guard normalization divisors against `<= 0.0f`; `[math_camera.h:Camera]` documents `yaw = -90` facing `-Z` and `pitch` in `[-89, +89]`.
  - `[frustum_cull.h:frustum_extract]` extracts Gribb/Hartmann planes from a column-major `mvp[16]` using Vulkan `[0, w]` depth (`Near = row2`, `Far = row3 - row2`) and normalizes only when `len > 1e-8f`; `[frustum_cull.h:frustum_test_aabb]` returns `0` immediately if any plane's P-vertex satisfies `a*px + b*py + c*pz + d < 0.0f`.
  - `[terrain_dem_data.h:s_demGrid]` covers `64x64` samples (`TERRAIN_DEM_NX x TERRAIN_DEM_NY`) over latitude `[21.800, 21.950]` and longitude `[-102.370, -102.245]` relative to `TERRAIN_DEM_BASE_ELEVATION` (`1871.0` m); `[terrain_dem_data.h:terrain_dem_clamp]` is NaN-safe (returns `lo` if `!(val >= lo)`); `[terrain_dem_data.h:terrain_dem_bilinear]` clamps cell indices `i, j <= 62`; `[terrain_dem_data.h:terrain_dem_seg_dist_side]` guards `l_sq < 1e-6`; rivers depress terrain within `d < valley_w` and faults apply `tanh(s / 40.0)` within `d < 120.0` m.
- **Simulation, streaming & resource ownership**:
  - `[chunk_system.h:chunk_system_load]` caps loaded chunks at `[chunk_system.h:MAX_CHUNKS]` (`16384`), defaults `chunkSize` to `128.0f` when parsed `< 1.0f`, skips entries with `count <= 0`, and returns `0` on I/O, allocation, or missing JSON keys.
  - `[sector_system.h:SectorSystem]` enforces fixed capacities `MAX_MACRO_SECTORS` (`512`), `MAX_CHUNKS_PER_SECTOR` (`256`), `MAX_DEFERRED_SECTOR_FREES` (`128`), and `MacroSector.filepath[128]`; sectors transition through states `SECTOR_STATE_UNLOADED` (`0`), `SECTOR_STATE_QUEUED_ASYNC` (`1`), `SECTOR_STATE_READY_CPU` (`2`), and `SECTOR_STATE_LOADED_GPU` (`3`); `[sector_system.h:sector_system_init]` targets `1 km x 1 km` quadrants (`<99MB` `.glb`, load radius `<= 2.0 km`) and returns `0` to fall back to monolithic loading if the manifest is absent.
  - `[traffic_system.h:TrafficIntersection]` runs a 6-phase cycle (`0..5`), `[traffic_system.h:TrafficSignal]` sets `intersectionIndex = -1` when unresolved and `phaseGroup` `0=NS`/`1=EW`, and `[traffic_system.h:traffic_system_force_mode]` expects `mode` in `{0, 1, 2}`.
  - `[ped_system.h:PedestrianState]` defines states `0..2`; `[ped_system.h:ped_system_spawn]` returns `1` on success and `0` on allocation failure.
  - `[obj_loader.h:obj_load]` and `[vulkan_gltf.h:gltf_load]` return `NULL` on error and transfer `Mesh*` ownership to the caller for release via `[obj_loader.h:obj_free]`.
- **Lighting, HUD, pause menu, telemetry & logging**:
  - `[lighting_system.h:lighting_system_init]` deduplicates streetlights within `25.0f` m horizontally (`d2 < 625.0f`); `[lighting_system.h:lighting_system_update]` early-returns on `!outUbo`, bounds candidate lights to `< 500` in `candidates[512]` (signals `< 650.0f` m, streetlights when `streetFactor > 0.02f` `< 700.0f` m, 2 beacons `< 850.0f` m), sets `flashPos[3] = 75.0f` and `flashDir[3] = 0.866f`, and leaves `sunDir`, `skyColor`, and `timeParams` to external callers.
  - `[debug_overlay.h:debug_overlay_add_rect]` and `[debug_overlay.h:debug_overlay_add_rect_z]` enforce `ov->vertCount + 6 <= DEBUG_MAX_VERTS` (`65536`), normalize pixels to Vulkan Y-down NDC, and set `emission = 10.0f`; `[debug_overlay.h:debug_overlay_add_char]` clamps `(int)ch - 32` outside `[0, 95]` to `0` (`' '`) at `z = 0.0005f`.
  - `[pause_menu.h:pause_menu_handle_key]` and `[pause_menu.h:pause_menu_render]` early-return when `!eng->isPaused`; cyclic index wrapping keeps `pauseMenuIndex` in `[0, MENU_COUNT)`, `timeScaleIndex` in `[0, NUM_TIME_SPEEDS)`, `timePresetIndex` in `[0, NUM_TIME_PRESETS)`, `camSpeedIndex` in `[0, NUM_CAM_SPEEDS)`, `trafficSignalMode` in `[0, 2]`, and `simHour` in `[0.0f, 24.0f)`; direct array indexing in `pause_menu_render` assumes these engine indices stay within bounds; `[pause_menu.h:pause_menu_toggle_fullscreen]` guards `!eng || !eng->window`.
  - `[telemetry.h:telemetry_frame_end]` averages across all `TELEMETRY_HISTORY_SIZE` (`60`) samples, guards `fps` against `avgFrameMs <= 0.0001f`, and guards `cullingEfficiencyPct` against `totalVerts == 0`; `[telemetry.h:telemetry_meets_iso25022]` requires `t != NULL`, `fps >= 60.0f`, `frameTimeMs <= 16.67f`, and (`totalVerts == 0 || cullingEfficiencyPct >= 40.0f`); `[telemetry.h:telemetry_export_json]` returns `0` if `!t || !filepath || !fopen(...)`.
  - `[logger.h:logger_log]` enforces GCC/Clang `printf` format checking (`format(printf, 5, 6)`); `[logger.h:logger_init]` documents `LOG_LEVEL` env-var override, `pthread_mutex_t` synchronization, `5 MiB x 3` rotation, and idempotent `[logger.h:logger_shutdown]`.
- **Vendored single-header library macro guards**:
  - `[cgltf.h:CGLTF_IMPLEMENTATION]` must be defined in **exactly one** translation unit before `#include "cgltf.h"` (defined in `src/vulkan_gltf.c` inside `#pragma GCC optimize("O0")`; `cgltf.h` also auto-defines it for `__INTELLISENSE__` or `__JETBRAINS_IDE__`). `[cgltf.h:cgltf_parse]`, `[cgltf.h:cgltf_parse_file]`, and `[cgltf.h:cgltf_load_buffers]` require non-`NULL` `cgltf_options*`; accessor unpacking/read helpers assume `[cgltf.h:cgltf_load_buffers]` was already called.
  - `[stb_image.h:STB_IMAGE_IMPLEMENTATION]` must be defined in **exactly one** translation unit before `#include "stb_image.h"` (defined in `src/vulkan_texture.c` alongside `STBI_ONLY_PNG`, `STBI_ONLY_JPEG`, and `STBI_NO_SIMD` inside `#pragma GCC optimize("O0")`). `[stb_image.h:STBI_MAX_DIMENSIONS]` defaults to `1 << 24` (`16777216`); defining only a partial subset of `STBI_MALLOC`, `STBI_FREE`, and `STBI_REALLOC`/`STBI_REALLOC_SIZED` triggers a compile-time `#error`.

## Side Effects

- **Inline mutations, I/O & SDL calls in header implementations**:
  - `[chunk_system.h:chunk_system_load]` reads `filepath` (`fopen`/`fread`/`fclose`), allocates/frees temporary heap memory, clears and populates `*cs`, and prints diagnostics to `stderr`/`stdout`.
  - `[debug_overlay.h:debug_overlay_begin]` resets `ov->vertCount = 0` and stores `screenW`/`screenH`; `[debug_overlay.h:debug_overlay_add_rect]`, `[debug_overlay.h:debug_overlay_add_rect_z]`, `[debug_overlay.h:debug_overlay_add_char]`, `[debug_overlay.h:debug_overlay_add_text]`, `[debug_overlay.h:debug_overlay_build_telemetry]`, and `[debug_overlay.h:debug_overlay_build_stats]` append HUD vertices into `ov->verts[]` and advance `ov->vertCount`.
  - `[lighting_system.h:lighting_system_init]` mutates `*sys` (`flashlightEnabled = 1`, `streetlightCount`, `streetlights[]`); `[lighting_system.h:lighting_system_toggle_flashlight]` toggles `sys->flashlightEnabled`; `[lighting_system.h:lighting_system_update]` writes `outUbo->lights[]`, `lightCount`, `flashlightOn`, `flashPos[4]`, and `flashDir[4]`.
  - `[math_camera.h:g_camera]` exposes mutable global camera state; `[math_camera.h:camera_get_vectors]` writes non-`NULL` `outForward`, `outRight`, and `outUp` parameters.
  - `[pause_menu.h:pause_menu_notify]` and its mutators mutate `VulkanEngine` UI/simulation flags (`notificationText`, `notificationTimer`, `timeScaleIndex`, `timeScale`, `timePresetIndex`, `simHour`, `timeFrozen`, `cullingEnabled`, `showTelemetry`, `camSpeedIndex`, `trafficSignalMode`, `framebufferResized`, `pauseMenuIndex`, `isPaused`), `lightingSystem`, and global `g_camera`; `[pause_menu.h:pause_menu_toggle_fullscreen]` and `[pause_menu.h:pause_menu_handle_key]` call `SDL_SetWindowFullscreen` and `SDL_SetRelativeMouseMode(SDL_TRUE)`; `[pause_menu.h:pause_menu_handle_key]` retains internal static `s_tp` and may clear `*outRunning`; `[pause_menu.h:pause_menu_render]` and `[pause_menu.h:pause_menu_render_notification]` append vertices to `DebugOverlay *ov`.
  - `[telemetry.h:telemetry_init]` zeros `*t` and reads `SDL_GetPerformanceFrequency()`; `[telemetry.h:telemetry_frame_start]`, `[telemetry.h:telemetry_cpu_begin]`, `[telemetry.h:telemetry_cpu_end]`, `[telemetry.h:telemetry_gpu_begin]`, `[telemetry.h:telemetry_gpu_end]`, and `[telemetry.h:telemetry_frame_end]` query `SDL_GetPerformanceCounter()` and mutate `*t` timing metrics and rolling history; `[telemetry.h:telemetry_export_json]` writes a JSON file to `filepath` via `fopen`/`fprintf`/`fclose`.
  - `[terrain_dem_data.h:terrain_dem_seg_dist_side]` and `[terrain_dem_data.h:terrain_dem_poly_dist_side]` write `*out_side` / `*out_min_d` output pointers.
  - `[vertex_format.h:vertex_get_attribute_descriptions]` populates the caller-provided `attrs[5]` array.
  - `[frustum_cull.h:frustum_extract]` and `[frustum_cull.h:frustum_test_aabb]` perform no external side effects.
- **Documented side effects of declared C module APIs**:
  - `[logger.h:logger_init]`, `[logger.h:logger_shutdown]`, `[logger.h:logger_set_level]`, and `[logger.h:logger_log]` (`LOG_*`) create `log_dir`, inspect `LOG_LEVEL`, acquire `pthread_mutex_t`, and write/rotate `street_vulkan.log` and `street_vulkan.jsonl`.
  - `[obj_loader.h:obj_load]`, `[road_graph.h:road_graph_load]`, `[traffic_system.h:traffic_system_load_json]`, `[vulkan_gltf.h:gltf_load]`, and `[vulkan_gltf.h:gltf_load_direct_vulkan]` read geometry/graph/JSON assets from disk (`FILE*` or `mmap`) and allocate heap or Vulkan buffers (paired with `obj_free`, `road_graph_free`, `traffic_system_free`).
  - `[car_system.h:car_system_init]`, `[traffic_system.h:traffic_system_init_gpu]`, `[sector_system.h:sector_system_load_gpu]`, and `[vulkan_memory_pool.h:vulkan_memory_pool_suballocate]` allocate/bind/map Vulkan `VkDeviceMemory`, `VkBuffer`, or `VkImage` resources (released via `car_system_free`, `traffic_system_free_gpu`, `sector_system_unload_gpu`/`sector_system_process_deferred_frees`/`sector_system_destroy`, and `vulkan_memory_pool_free_suballocation`/`vulkan_memory_pool_destroy`); `[car_system.h:car_system_render]` and `[traffic_system.h:traffic_system_render]` record draw commands into `VkCommandBuffer`.

- **Vendored library side effects**:
