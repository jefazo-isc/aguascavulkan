# Engine & Simulation Runtime (`src`)

## Overview
The `src` package implements the C runtime for StreetVulkan (`street_vulkan`), compiling all 16 `.c` translation units against header contracts in `include/*.h` and linking `SDL2`, `Vulkan`, `libm`, and `pthread` (see `Makefile`). It provides the SDL2/Vulkan application entrypoint, thread-safe concurrent logging, asset loaders (Wavefront OBJ/MTL, glTF/GLB, RGP1 road graphs, and PNG/JPEG textures), a pooled Vulkan device/memory/swapchain/pipeline backend, async 1 km x 1 km macro-sector streaming, 6-phase traffic signal simulation, instanced vehicle kinematics, and pedestrian state updates.

Header-inline subsystems in `include/math_camera.h`, `include/lighting_system.h`, `include/chunk_system.h`, `include/frustum_cull.h`, `include/debug_overlay.h`, `include/pause_menu.h`, `include/telemetry.h`, `include/terrain_dem_data.h`, and `include/vertex_format.h` are consumed by `src/*.c` rather than exported from this package. No subdirectories exist inside `src/`.

## Interface

### Application Entrypoint & Global Camera State (`include/vulkan.h`, `include/math_camera.h`)
- `[main.c:main]` `int main(void)` — Initializes logging (`logs`), SDL2 video, a hidden 1024x768 resizable Vulkan window, and `VulkanEngine`; executes the fixed-timestep simulation loop, SDL input/window event handling, and teardown.
- `[main.c:TEST_FRAMES]` — Environment variable read via `getenv("TEST_FRAMES")` to terminate after `N` rendered frames and print FPS, draw-call, and vertex telemetry to `stdout`.
- `[main.c:TEST_PAUSE]` — Environment variable read via `getenv("TEST_PAUSE")` to initialize `eng.isPaused = 1`.
- `[math_camera.c:g_camera]` `Camera g_camera` — Global `Camera` instance initialized at `pos = {954.4f, 8.8f, 793.1f}`, `yaw = -45.7f`, `pitch = 4.9f`, `moveSpeed = 35.0f`, `sprintMultiplier = 4.0f`, `mouseSensitivity = 0.12f`, `mouseCaptured = 1`.

### Vulkan Engine Orchestration (`include/vulkan.h`, `include/vulkan_types.h`)
- `[vulkan.c:vulkan_get_ground_elevation]` `float vulkan_get_ground_elevation(VulkanEngine *eng, float x, float z)` — Returns terrain ground elevation at `(x, z)` via `terrain_dem_get_elevation`.
- `[vulkan.c:vulkan_init]` `int vulkan_init(VulkanEngine *eng, SDL_Window *window)` — Initializes device/instance, memory pools, swapchain, render pass, framebuffers, sync primitives, graphics pipeline, timestamp query pool, textures, traffic/lighting/car/chunk/sector systems, primary and auxiliary geometry, and HUD buffers.
- `[vulkan.c:vulkan_update_simulation]` `void vulkan_update_simulation(VulkanEngine *eng, float fixedDeltaTime)` — Steps simulated solar hour, traffic signal phases, and vehicle kinematics at a fixed timestep.
- `[vulkan.c:vulkan_draw]` `void vulkan_draw(VulkanEngine *eng, float deltaTime)` — Acquires swapchain image, updates sector streaming, updates lighting UBO and dynamic buffers, records draw commands (sectors or culled chunks, auxiliary OBJs, instanced cars, traffic lenses, HUD), submits GPU work, and presents.
- `[vulkan.c:vulkan_destroy]` `void vulkan_destroy(VulkanEngine *eng)` — Waits for device idle and tears down simulation systems, GPU/CPU geometry buffers, textures, pipeline/sync, swapchain, memory pools, and Vulkan device/instance.
- `[vulkan.c:STREET_DEBUG_ROAD_GRAPH]` — Environment variable read via `getenv("STREET_DEBUG_ROAD_GRAPH")` to append road-graph debug ribbon geometry into `eng->auxVertexBuffer`.

### Vulkan Device, Memory, Swapchain, Pipeline & Textures (`include/vulkan_device.h`, `include/vulkan_memory_pool.h`, `include/vulkan_swapchain.h`, `include/vulkan_pipeline.h`, `include/vulkan_texture.h`)

- `[vulkan_pipeline.c:create_render_pass]` `int create_render_pass(VulkanEngine *eng)` — Creates `eng->renderPass` with color and depth attachments.

- `[vulkan_texture.c:cleanup_texture_resources]` `void cleanup_texture_resources(VulkanEngine *eng)` — Destroys lighting UBO buffers, descriptor pool, texture sampler, and texture images/views.

## Invariants

### Main Loop, Camera & Logging
- `[main.c:main]` Per-frame `deltaTime` is clamped at `0.25f` s, and `vulkan_update_simulation` executes only in fixed `FIXED_DELTA_TIME` (`1.0f / 60.0f`) steps; `g_camera.pitch` is clamped to `[-89.0f, 89.0f]`; camera movement and mouse-look run only when `!eng.isPaused && g_camera.mouseCaptured`.
- `[main.c:main]` Window initializes hidden, renders one initial frame (`0.016f`) prior to `SDL_ShowWindow`, skips `vulkan_draw` while minimized (`SDL_Delay(16)`), and throttles title updates to `0.15f` s intervals.
- `[math_camera.c:g_camera]` Defines the single global `Camera` storage declared `extern` in `include/math_camera.h` with deterministic startup coordinates (`{954.4f, 8.8f, 793.1f}`).
- `[logger.c:g_logger_mutex]` All public logger operations acquire `g_logger_mutex`; `ensure_dir_exists` rejects paths `>= LOGGER_PATH_MAX` (512 bytes) and `logger_init` defaults empty/`NULL` `log_dir` to `"logs"`.
- `[logger.c:logger_log]` Discards records below `g_min_level`, caps formatted message body at `LOGGER_MSG_MAX` (2048 bytes), strips trailing `\r`/`\n`, defaults `NULL`/empty tag and file to `"App"` and `"unknown"`, writes `>= LOG_LEVEL_WARN` to `stderr` (with `(file:line)`) and lower levels to `stdout`, emits ANSI escape colors only when `isatty(fileno(out)) != 0`, and rotates files at `>= LOGGER_MAX_FILE_BYTES` (5 MiB) via `fstat` across up to `LOGGER_MAX_BACKUPS` (3) backups (`<path>.1`..`<path>.3`) (`[logger.c:rotate_if_needed]`).

### Vulkan Core, Pools, Swapchain, Pipeline & Textures
- `[vulkan_device.c:init_vulkan_instance_and_device]` Targets `VK_API_VERSION_1_2` (`"StreetView Vulkan"`); under `DEBUG`, requires `VK_LAYER_KHRONOS_validation` (`[vulkan_device.c:check_validation_layer_support]`) or fails returning `0`; selects a physical device supporting `VK_KHR_SWAPCHAIN_EXTENSION_NAME` and a single queue family for graphics + presentation (preferring `VK_PHYSICAL_DEVICE_TYPE_DISCRETE_GPU`); enables `samplerAnisotropy` only when supported.
- `[vulkan_device.c:cleanup_vulkan_instance_and_device]` Destroys non-null handles in strict order `device -> surface -> debugMessenger (DEBUG) -> instance`, resetting each to `VK_NULL_HANDLE`.
- `[vulkan.c:vulkan_init]` Zeroes `*eng`, separates 64 MB `vramBufferPool` and `vramImagePool` (buffer-image granularity isolation) plus 16 MB `HOST_VISIBLE | HOST_COHERENT` `hostVisiblePool`; invokes `vulkan_destroy` on post-device failure; enforces 3-tier geometry loading (`[vulkan.c:load_primary_geometry]`): (0) `models/sectors.json` (`useSectorSystem = 1`), (1) `models/aguascalientes_sector1.glb` via `gltf_load_direct_vulkan`, (2) `models/aguascalientes_sector1.obj` or fallback `models/test.obj`; disables chunks if `indexCount > 0 && chunkSystem.totalVerts > indexCount`.
- `[vulkan.c:upload_buffer_to_gpu]` Requires `cpuData != NULL`, `byteSize > 0`, and `outBuffer != NULL`, freeing `cpuData` unconditionally; uses direct mapped upload iff `is_direct_host_visible_uma` sees `DEVICE_LOCAL | HOST_VISIBLE`, otherwise stages via `hostVisiblePool` into `vramBufferPool` and destroys/frees staging resources regardless of copy outcome.
- `[vulkan.c:vulkan_draw]` Early-returns on zero drawable size; runs `sector_system_update(..., 2000.0f)` only after `acquire_frame_image` succeeds; projects with `DEG2RAD(60.0f)` FOV, near `1.0f`, far `15000.0f`; culls monolithic chunks beyond `2000.0f` XZ distance or outside frustum while clamping `(c->start + c->count)` against `indexCount` / `baseVertexCount`; guards timestamp query reads (`[vulkan.c:read_frame_gpu_timestamp]`) by `timestampValid[frameIdx]`.
- `[vulkan.c:vulkan_destroy]` Stalls on `vkDeviceWaitIdle` before destroying buffers, pipelines, sync objects, swapchain, and memory pools (`vramBufferPool`, `vramImagePool`, `hostVisiblePool`) prior to `cleanup_vulkan_instance_and_device`.
- `[vulkan_memory_pool.c:vulkan_memory_pool_suballocate]` Requires non-null `pool`, valid `device`, `size > 0`, clamps `alignment == 0` to `1`, and allocates via best-fit free region (splitting non-zero prefix/suffix), existing block tail bump, or new block up to `VK_POOL_MAX_BLOCKS` (128); blocks in `VK_MEMORY_PROPERTY_HOST_VISIBLE_BIT` pools are persistently mapped across their entire size; `[vulkan_memory_pool.c:vulkan_memory_pool_bind_buffer]` and `[vulkan_memory_pool.c:vulkan_memory_pool_bind_image]` verify `memoryTypeIndex < 32` and `memoryTypeBits` compatibility and roll back suballocations if `vkBind*Memory` fails.
- `[vulkan_memory_pool.c:vulkan_memory_pool_free_suballocation]` Ignores invalid handles, `size == 0`, unknown blocks, or out-of-bounds spans; coalesces contiguous free regions across `freeRegions` (`VK_POOL_MAX_FREE_REGIONS` = 256) and dynamically doubled `extraFreeRegions`, rewinding `block->allocatedOffset` when tail-contiguous.
- `[vulkan_swapchain.c:recreate_swapchain]` Returns `0` immediately without waiting for device idle when drawable width or height is `0`; otherwise waits via `vkDeviceWaitIdle`, tears down framebuffers/depth/old views before creating the replacement swapchain with `oldSwapchain`, and clears `framebufferResized = 0` only after depth and framebuffer recreation succeed.
- `[vulkan_swapchain.c:create_swapchain_and_depth]` Prefers `VK_FORMAT_B8G8R8A8_SRGB` with `VK_COLOR_SPACE_SRGB_NONLINEAR_KHR`, requires `VK_PRESENT_MODE_FIFO_KHR` and `VK_COMPOSITE_ALPHA_OPAQUE_BIT_KHR`, and selects depth format in strict order `D32_SFLOAT -> D32_SFLOAT_S8_UINT -> D24_UNORM_S8_UINT` (`[vulkan_swapchain.c:findSupportedDepthFormat]`).
- `[vulkan_pipeline.c:create_pipeline_and_descriptors]` Expects `"main"` entry points in `shaders/vertex.spv` and `shaders/fragment.spv` (rejecting non-positive or non-4-byte-aligned SPIR-V files in `[vulkan_pipeline.c:read_spv_file]`); binds 2 vertex streams (binding 0 per-vertex via `vertex_get_binding_description`, binding 1 per-instance stride 96 bytes for `CarInstanceData`), 11 attributes, `TRIANGLE_LIST`, `CULL_MODE_NONE`, `LESS_OR_EQUAL` depth test/write, alpha blending, 4 fragment descriptor bindings (`0,1,3` `COMBINED_IMAGE_SAMPLER`, `2` `UNIFORM_BUFFER`), and `sizeof(PushConstants)` push constants on `VERTEX_BIT | FRAGMENT_BIT`.
- `[vulkan_texture.c:init_satellite_texture]` Uses `VK_FORMAT_R8G8B8A8_SRGB` across all textures; disables mipmaps (`mipLevels = 1`, no `TRANSFER_SRC_BIT`) when blit src/dst features are unsupported; resolves satellite pixels in priority order (`[vulkan_texture.c:load_satellite_pixels]`): 4-quadrant PNG mosaic (`assets/` or `../assets/`), explicit `texturePath`, fallback asset paths, or 4x4 RGBA fallback; binds images strictly through `eng->vramImagePool` (`[vulkan_texture.c:create_gpu_image]`) with no dedicated fallback; frees CPU pixel buffers unconditionally (`[vulkan_texture.c:upload_image_and_view]`); binds descriptor 3 to `photoImageView` if valid else `facadeImageView`.

### Loaders, Streaming & Traffic/Agent Simulation
- `[obj_loader.c:obj_load]` Caps line buffer at 4096 bytes, face vertices at 64, material table at `MAX_OBJ_MATERIALS` (128), and `.mtl` path at 512 bytes; fan-triangulates polygons with `>= 3` refs; leaves returned `Mesh::indices == NULL` and `Vertex::emission == 0.0f`; `d > 1.01f` encodes custom material ID in `.a` (`map_Kd` sets `.a = 0.0f` only if `<= 1.01f`).
- `[vulkan_gltf.c:gltf_load]` `[vulkan_gltf.c:gltf_load_direct_vulkan]` Memory-maps files read-only (`MAP_SHARED`, `MADV_SEQUENTIAL`); skips non-triangle or position-less primitives and rejects `totalVertices == 0`; defaults missing attributes (`normal = (0,1,0)`, `uv = (0,0)`, `color = (1,1,1,0)` with texcoords or `(1,1,1,1)` without); `_EMISSION`/`EMISSION`/`_EMISSION_FACTOR` overrides material emission; `gltf_load_direct_vulkan` requires non-null `mappedPtr` from `eng->hostVisiblePool` on `eng->vertexBuffer` and sets `vertexData = NULL`, `indexData = NULL`.
- `[road_graph.c:road_graph_load]` Validates 4-byte binary magic `"RGP1"`, clamps every edge length (`pt_count >= 2` and in-bounds points) to `>= 0.1f`, omits reverse CSR incidence on `oneway` edges, and guards against `UINT32_MAX` incidence overflow.
- `[sector_system.c:read_sector_glb_attributes]` `[sector_system.c:interleave_sector_vertices]` Enforces GLB magic `0x46546C67` and Chunk 1 `BIN` type `0x004E4942`, overriding manifest `vertexCount` with `c1_hdr[0] / 56` when positive and reading `vcount * 52` bytes arranged as 5 contiguous SOA blocks (`pos` 12B, `norm` 12B, `uv` 8B, `col` 16B, `em` 4B).
- `[sector_system.c:sector_worker_thread]` `[sector_system.c:sector_system_update]` Preserves async cancellation via `asyncGen` monotonic tokens checked under `ss->mutex`; transitions `QUEUED_ASYNC -> READY_CPU` only if `!shutdownWorker` and token matches; drains at most 2 in-range `READY_CPU` sectors to GPU per frame (`unloadRadius = loadRadius + 400.0f`); enforces sync fallback while `activeLoadedSectors == 0` or if worker start fails; enqueues unloaded GPU handles with `framesRemaining = MAX_FRAMES_IN_FLIGHT + 1` and flushes via `vkDeviceWaitIdle` if `deferredFreeCount >= MAX_DEFERRED_SECTOR_FREES`.
- `[traffic_system.c:traffic_system_update_simulation]` Enforces deterministic 6-phase intersection cycle (`0: NS Green -> 1: NS Amber -> 2: All Red -> 3: EO Green -> 4: EO Amber -> 5: All Red`), resetting out-of-range phases to `0`; `[traffic_system.c:traffic_system_init_gpu]` requires non-null `mappedPtr` across all `MAX_FRAMES_IN_FLIGHT` buffers and synthesizes 6-vertex lens quads when initial mesh indices are absent/invalid; `[traffic_system.c:traffic_system_update_gpu_frame]` sets active lens `emission = 6.0f` and inactive RGB `(0.03f, 0.03f, 0.04f)`, `emission = 0.0f`.
- `[car_system.c:car_system_update]` Respawns vehicles >800 m from camera, with `v_desired <= 0`, NaN coordinates, or `pt_count < 2`; uses power-of-two spatial hash (`CAR_GRID_SIZE = 1024`, cell 28 m) and same-edge hash (`CAR_EDGE_HASH_SIZE = 512`), enforcing `MIN_FOLLOW_DIST` (5.0 m), `SAFE_TIME_HEADWAY` (1.2 s), and RED/AMBER braking within 35 m (`<= 5.0` m stop); `staticDummyBuffer` supplies identity model and `tint.a = 0.0f` for static draws vs `1.0f` for vehicles.
- `[ped_system.c:ped_system_update]` Early-returns on `!sys || deltaTime <= 0.0f`; polls traffic within `12.0f` m only when `traffic != NULL && state != PED_WALKING`; halts movement in `PED_WAITING_RED` and advances XZ coordinates otherwise without modifying Y.

## Side Effects
- **Filesystem I/O**: Reads `models/sectors.json`, sector `.glb` files, `models/aguascalientes_sector1.{glb,obj}`, `models/test.obj`, `models/road_network.bin`, `models/traffic_signals.json`, `models/chunks.json`, `models/cars/car_*.glb`, `models/generated/*.obj`, `models/generated/photo_*.{jpg,png}`, `models/texture_atlas_16x16.png`, `assets/*`, and `shaders/{vertex,fragment}.spv`; `[logger.c:logger_init]` and `[logger.c:logger_log]` create `"logs"` directories (`mkdir(..., 0755)`), append/flush `street_vulkan.log` and `street_vulkan.jsonl`, and rotate oversized logs across up to 3 backups (`<path>.1`..`<path>.3`).
- **Windowing, Threading & Global State**: `[main.c:main]` mutates SDL video/window title/relative mouse capture and global `g_camera`; `[vulkan_gltf.c:gltf_load_direct_vulkan]` and `[vulkan.c:vulkan_init]` invoke `SDL_PumpEvents()`; `[vulkan_texture.c:init_satellite_texture]` mutates `stb_image` global state (`stbi_set_flip_vertically_on_load(0)`); `[car_system.c:car_system_init]` seeds `srand()` and `[car_system.c:car_system_update]` advances `rand()`; `[sector_system.c:start_sector_worker]` spawns a POSIX `pthread` worker synchronized by `ss->mutex` and `ss->cond`; `[logger.c:logger_log]` writes to `stdout`/`stderr` under `g_logger_mutex`.
- **Vulkan GPU Allocation, Mapped Memory Writes & Synchronization**: Allocates `VkDeviceMemory` blocks via `vkAllocateMemory` and maps host-visible memory (`vkMapMemory`) in `vulkan_memory_pool.c`, `car_system.c`, `sector_system.c`, `vulkan_swapchain.c`, and `vulkan_texture.c`; writes directly to mapped GPU buffers every frame (`car_system_render`, `traffic_system_update_gpu_frame`, `vulkan.c:render_hud_overlay`, `vulkan.c:vulkan_draw`); submits synchronous one-time copy/blit command buffers blocking via `vkQueueWaitIdle` or `vkWaitForFences(..., UINT64_MAX)` (`vulkan.c`, `car_system.c`, `sector_system.c`, `vulkan_texture.c`); stalls entire GPU via `vkDeviceWaitIdle` during teardown, swapchain recreation, and deferred-free queue saturation.
- **Heap Memory & Process Diagnostics**: Allocates/reallocates/frees CPU arrays across asset loaders, simulation systems, and pool overflow lists; logs diagnostic output to `stdout`, `stderr`, and logger streams.
