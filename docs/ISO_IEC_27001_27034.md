# Seguridad de la Información y de Aplicaciones — ISO/IEC 27001 & ISO/IEC 27034

## 1. Propósito y Alcance
Este documento establece los controles de seguridad de la información (**ISO/IEC 27001**) y el marco de seguridad de aplicaciones (**ISO/IEC 27034**) aplicables al repositorio **StreetVulkan** (motor gráfico en C11/Vulkan, shaders GLSL y herramientas de procesamiento geoespacial en Python).

## 2. Controles ISO/IEC 27001 (Anexo A Aplicables)
| Control | Descripción | Evidencia en StreetVulkan |
|---|---|---|
| **A.8.9** Gestión de configuración | Control estricto de binarios, caches y secretos fuera de Git | `.gitignore` y compilación determinista en [Makefile](file:///home/yahir/vulkan/Makefile) |
| **A.8.25** Ciclo de vida de desarrollo seguro | Compilación con advertencias estrictas y sanitizadores | `CFLAGS = -Wall -Wextra -O2` y target `asan-test` (ASan + UBSan) |
| **A.8.28** Codificación segura | Prevención de desbordamientos y fugas de secretos | Escaneo automático en [audit_iso27001_27034.py](file:///home/yahir/vulkan/tools/metrics/audit_iso27001_27034.py) |
| **A.8.8** Gestión de vulnerabilidades técnicas | Auditoría continua en integración continua | Pipeline en [.github/workflows/ci.yml](file:///home/yahir/vulkan/.github/workflows/ci.yml) |

## 3. Marco ISO/IEC 27034 (Seguridad de Aplicaciones)
### 3.1 Nivel Organizacional (ONF) y de Aplicación (ANF)
- **Lenguaje C / Vulkan (`src/`, `include/`)**:
  - Prohibición absoluta de funciones sin límite de búfer como `gets(`.
  - Vigilancia de funciones legadas (`sprintf(`, `vsprintf(`, `strcpy(`, `strcat(`) favoreciendo `snprintf` y `strncpy` con terminación nula explícita.
  - Verificación de memoria en tiempo de ejecución mediante AddressSanitizer y UndefinedBehaviorSanitizer (`make asan-test`).
- **Herramientas Python (`tools/`)**:
  - Uso exclusivo de subprocesos parametrizados sin invocación insegura de shell con entradas externas.
  - Prohibición de llaves privadas, tokens de API o credenciales embebidas en código fuente.

## 4. Verificación Automatizada
El auditor [audit_iso27001_27034.py](file:///home/yahir/vulkan/tools/metrics/audit_iso27001_27034.py) ejecuta de forma automática:
1. Escaneo de archivos `.c`/`.h` propios (excluyendo cabeceras de terceros `cgltf.h`, `stb_image.h`, `stb_truetype.h`) para detectar llamadas críticas inseguras y monitorear llamadas legadas.
2. Escaneo de todo el código propio (`.c`, `.h`, `.py`) para descartar llaves privadas o tokens hardcodeados.
3. Validación de flags de compilación segura (`-Wall -Wextra`) y control de exclusión `.gitignore`.
4. Integración directa en el evaluador maestro [evaluate_iso25040.py](file:///home/yahir/vulkan/tools/metrics/evaluate_iso25040.py).
