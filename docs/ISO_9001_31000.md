# Sistema de Gestión de Calidad y Riesgos — ISO 9001 & ISO 31000

## 1. Sistema de Gestión de Calidad (ISO 9001 — Ciclo PHVA / PDCA)
**StreetVulkan** estructura su aseguramiento de calidad bajo el ciclo **Planificar-Hacer-Verificar-Actuar (PHVA)**:
- **Planificar**: Especificación de requisitos, arquitectura modular por macro-sectores (`1024m`) y objetivos cuantitativos en [ISO_IEC_25010.md](ISO_IEC_25010.md) y [ESTIMACION_Y_TRAZABILIDAD.md](ESTIMACION_Y_TRAZABILIDAD.md).
- **Hacer**: Desarrollo incremental en C11/Vulkan, shaders GLSL y scripts Python con control estricto de memoria.
- **Verificar**: Compuertas automáticas en [Makefile](../Makefile) (`make test`, `make asan-test`, `make metrics`, `make quality`) y scorecard consolidado [evaluate_iso25040.py](../tools/metrics/evaluate_iso25040.py).
- **Actuar**: Registro transparente de deuda técnica (`CC > 20`) y remediación continua sin ocultar umbrales.

## 2. Gestión de Riesgos Técnicos (ISO 31000)
| ID | Riesgo Identificado | Probabilidad | Impacto | Mitigación Implementada |
|---|---|---|---|---|
| **R-01** | Agotamiento de RAM / uso de swap durante regeneración de sectores | Media | Alto | Subprocesos aislados por sector, límites de memoria (`1800 MB`), `nice=15` y streaming en [generate_sector.py](../tools/generate_sector.py) |
| **R-02** | Fugas o corrupción de memoria en C/Vulkan | Media | Crítico | Pool de memoria dedicado ([vulkan_memory_pool.c](../src/vulkan_memory_pool.c)) y validación periódica con `make asan-test` |
| **R-03** | Inconsistencia entre `sectors.json`, `.glb` y `chunks.json` | Baja | Alto | Auditoría automática ISO 25012/25024 ([validate_data_quality.py](../tools/metrics/validate_data_quality.py)) tras cada regeneración |
| **R-04** | Complejidad ciclomática elevada (`CC > 20`) en módulos legados C | Alta | Medio | Monitoreo transparente en [measure_maintainability.py](../tools/metrics/measure_maintainability.py) para refactorización progresiva |
| **R-05** | Exposición accidental de credenciales o llamadas C inseguras | Baja | Alto | Auditoría automática ISO 27001/27034 ([audit_iso27001_27034.py](../tools/metrics/audit_iso27001_27034.py)) |

## 3. Verificación Automatizada
La presencia de artefactos SGC, documentación y compuertas de calidad se revisa mediante [audit_iso9001_31000.py](../tools/metrics/audit_iso9001_31000.py); esta auditoría interna no representa una certificación ISO.
