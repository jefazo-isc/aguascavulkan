# Sistema de Gestión de Calidad y Riesgos — ISO 9001 & ISO 31000

## 1. Sistema de Gestión de Calidad (ISO 9001 — Ciclo PHVA / PDCA)
**StreetVulkan** estructura su aseguramiento de calidad bajo el ciclo **Planificar-Hacer-Verificar-Actuar (PHVA)**:
- **Planificar**: Especificación de requisitos, arquitectura modular por macro-sectores (`1024m`) y objetivos cuantitativos en [ISO_IEC_25010.md](file:///home/yahir/vulkan/docs/ISO_IEC_25010.md) y [ESTIMACION_Y_TRAZABILIDAD.md](file:///home/yahir/vulkan/docs/ESTIMACION_Y_TRAZABILIDAD.md).
- **Hacer**: Desarrollo incremental en C11/Vulkan, shaders GLSL y scripts Python con control estricto de memoria.
- **Verificar**: Compuertas automáticas en [Makefile](file:///home/yahir/vulkan/Makefile) (`make test`, `make asan-test`, `make metrics`, `make quality`) y scorecard consolidado [evaluate_iso25040.py](file:///home/yahir/vulkan/tools/metrics/evaluate_iso25040.py).
- **Actuar**: Registro transparente de deuda técnica (`CC > 20`) y remediación continua sin ocultar umbrales.

## 2. Gestión de Riesgos Técnicos (ISO 31000)
| ID | Riesgo Identificado | Probabilidad | Impacto | Mitigación Implementada |
|---|---|---|---|---|
| **R-01** | Agotamiento de RAM / uso de swap durante regeneración de sectores | Media | Alto | Subprocesos aislados por sector, límites de memoria (`1800 MB`), `nice=15` y streaming en [generate_sector.py](file:///home/yahir/vulkan/tools/generate_sector.py) |
| **R-02** | Fugas o corrupción de memoria en C/Vulkan | Media | Crítico | Pool de memoria dedicado ([vulkan_memory_pool.c](file:///home/yahir/vulkan/src/vulkan_memory_pool.c)) y validación periódica con `make asan-test` |
| **R-03** | Inconsistencia entre `sectors.json`, `.glb` y `chunks.json` | Baja | Alto | Auditoría automática ISO 25012/25024 ([validate_data_quality.py](file:///home/yahir/vulkan/tools/metrics/validate_data_quality.py)) tras cada regeneración |
| **R-04** | Complejidad ciclomática elevada (`CC > 20`) en módulos legados C | Alta | Medio | Monitoreo transparente en [measure_maintainability.py](file:///home/yahir/vulkan/tools/metrics/measure_maintainability.py) para refactorización progresiva |
| **R-05** | Exposición accidental de credenciales o llamadas C inseguras | Baja | Alto | Auditoría automática ISO 27001/27034 ([audit_iso27001_27034.py](file:///home/yahir/vulkan/tools/metrics/audit_iso27001_27034.py)) |
