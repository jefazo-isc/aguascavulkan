# Reglas del Agente

- **Subir cambios a Git al terminar**: Siempre que termines una tarea de código o configuración y las pruebas/verificaciones pasen correctamente, haz `git add`, `git commit` (con un mensaje descriptivo tipo Conventional Commits) y `git push` a la rama remota correspondiente (`origin main` o la rama activa) antes de dar por finalizada la tarea. Nunca hagas `push --force` ni subas secretos o archivos temporales.
