- **Fuente:** [Overture Maps Foundation](https://overturemaps.org/), tema `buildings`, descargado con el CLI `overturemaps` para el recuadro de Aguascalientes (lat 21.80–21.95, lon −102.370 – −102.245).
- **Proveedores incluidos:** OpenStreetMap, Microsoft ML Buildings y Google Open Buildings.
- **Licencia:** [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). `city_buildings.bin` es una base de datos derivada (huellas simplificadas y alturas estimadas) y se distribuye bajo la misma licencia ODbL.
- **Atribución:** © colaboradores de OpenStreetMap, Overture Maps Foundation, Microsoft y Google.
