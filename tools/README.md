# StreetVulkan Pipeline & Asset Tools (`tools`)

## Overview

Offline geospatial data acquisition, 3D city mesh generation, road/traffic graph compilation, vehicle/pedestrian asset synthesis, Gemini-powered photo/orthophoto 3D extraction, WebAssembly toolchain packaging, supply-chain planning, and runtime capture scripts for StreetVulkan. The main pipeline orchestrates Aguascalientes terrain/DEM, OSM/Overture/DENUE ingestion, procedural architecture/props/wiring, and chunked glTF 2.0 (`.glb`) streaming sectors consumed by the C/Vulkan engine and its WASM build.

## Interface

- Subdirectory package: [metrics](./metrics/README.md) — ISO/IEC 25040/25023/25012/27001/29119/9001 quality, maintainability, security, and dataset compliance suite (`evaluate_iso25040.py`, `measure_iso25023.py`, `measure_maintainability.py`, `validate_data_quality.py`, `audit_iso27001_27034.py`, `audit_iso29119.py`, `audit_iso9001_31000.py`, `check_traceability.py`, `estimate_cocomo_fp.py`).
