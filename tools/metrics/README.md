# StreetVulkan Quality Metrics & Compliance (`tools/metrics`)

## Overview

Automated software quality, sizing, security, maintainability, traceability, and dataset integrity evaluation suite for StreetVulkan. `evaluate_iso25040.py` acts as the master ISO/IEC 25040 & 25041 orchestrator invoked by `make metrics`, executing eight standalone verifier scripts across C/header sources, GLSL shaders, Python tools, generated geospatial/3D artifacts, tests, and governance documentation, then compiling results into `build/quality_scorecard.json`.

## Interface

- `[evaluate_iso25040.py:ROOT]` — Repository root resolved two levels above `tools/metrics/`.
- `[evaluate_iso25040.py:classify_exit_code]` — `classify_exit_code(exit_code)` maps `0` -> `"PASS"`, `2` -> `"WARN"`, and any other integer -> `"FAIL"`.
- `[evaluate_iso25040.py:run_step]` — `run_step(name, standard, cmd)` runs `cmd` in `ROOT` and returns `{name, standard, status, passed, warned, exit_code, output, errors}`.
- `[evaluate_iso25040.py:main]` / `[evaluate_iso25040.py:--strict]` — CLI entry point `main(argv=None)` running all 8 evaluation steps, writing `build/quality_scorecard.json`, and returning exit code `0` or `1`; `--strict` (`action="store_true"`) treats `WARN` checks as failures.
- `[measure_iso25023.py:ROOT]`, `[measure_iso25023.py:TOOLS_DIR]` — Repository root and `ROOT/tools` path (inserted into `sys.path[0]` at import time).
- `[measure_iso25023.py:run_cmd]` — `run_cmd(cmd, cwd=ROOT)` returns `(returncode, stdout + stderr, elapsed_monotonic_s)`.
- `[measure_iso25023.py:check_shader_compilation]`, `[measure_iso25023.py:_compile_single_c]`, `[measure_iso25023.py:check_compiler_warnings]` — Automated checks `Q-CMP-02` (SPIR-V compilation via `glslangValidator`), `Q-MNT-01` (`-Wall -Wextra` warning count), and `Q-PRT-02` (parallel C compile wall time).
- `[measure_iso25023.py:check_secret_leakage]`, `[measure_iso25023.py:check_glb_size]`, `[measure_iso25023.py:check_dem_topography_precision]` — Automated checks `Q-SEC-01` (tracked-file API key scan), `Q-PRF-03` (sector/main GLB size), and `Q-FNC-02` (C `terrain_dem_get_elevation()` vs. `geo_dem.TerrainElevation.get_real_topography()`).
- `[measure_iso25023.py:check_modular_architecture]`, `[measure_iso25023.py:check_makefile_targets]`, `[measure_iso25023.py:check_vulkan_device_extensions]` — Automated checks `Q-MNT-02` (`.c`/`.h` pairing), `Q-MNT-03` (`Makefile` targets), and `Q-PRT-01` (`deviceExtensions[]` in `src/vulkan_device.c`).
- `[measure_iso25023.py:_validate_single_glb]`, `[measure_iso25023.py:check_glb_conformance]`, `[measure_iso25023.py:main]` — Helper validating GLB v2 binary headers/JSON chunks (`Q-CMP-01`) across `models/cars/*.glb` and `models/peds/*.glb`, and CLI entry point `main()`.
- `[measure_maintainability.py:ROOT]`, `[measure_maintainability.py:THIRD_PARTY]`, `[measure_maintainability.py:BRANCH_RE]`, `[measure_maintainability.py:FUNC_HDR_RE]`, `[measure_maintainability.py:NON_FUNC_NAMES]` — Constants and regexes for C/H maintainability and McCabe complexity analysis (`THIRD_PARTY = {"cgltf.h", "stb_image.h"}`).
- `[measure_maintainability.py:strip_comments_and_strings]`, `[measure_maintainability.py:extract_function_name]`, `[measure_maintainability.py:analyze_c_file]`, `[measure_maintainability.py:collect_source_files]`, `[measure_maintainability.py:evaluate_maintainability]` — Functions computing per-file line counts, comment density, and approximate McCabe cyclomatic complexity (`cc_threshold=20`, `min_comment_pct=5.0`).
- `[measure_maintainability.py:main]` / `[measure_maintainability.py:--strict]` — CLI entry point `main(argv=None)` returning `0`, `2` (`WARN` when technical debt exists), or `1` (`FAIL` when `--strict` is set and technical debt exists).
- `[validate_data_quality.py:ROOT]`, `[validate_data_quality.py:check_traffic_signals]`, `[validate_data_quality.py:check_classified_buildings]`, `[validate_data_quality.py:check_sectors_consistency]`, `[validate_data_quality.py:check_road_network_bin]`, `[validate_data_quality.py:check_chunks_json]`, `[validate_data_quality.py:check_dem_caches]`, `[validate_data_quality.py:check_manifests]`, `[validate_data_quality.py:check_denue_csv]`, `[validate_data_quality.py:main]` — ISO/IEC 25012 & 25024 dataset validators for `models/` artifacts and CLI entry point `main()`.
- `[audit_iso27001_27034.py:ROOT]`, `[audit_iso27001_27034.py:THIRD_PARTY_HEADERS]`, `[audit_iso27001_27034.py:CRITICAL_UNSAFE_C]`, `[audit_iso27001_27034.py:ADVISORY_UNSAFE_C]`, `[audit_iso27001_27034.py:SECRET_PATTERNS]`, `[audit_iso27001_27034.py:iter_owned_c_files]`, `[audit_iso27001_27034.py:iter_code_files]`, `[audit_iso27001_27034.py:check_security]`, `[audit_iso27001_27034.py:main]` — Security audit scanning owned `.c`/`.h` files for unsafe C calls and `.c`/`.h`/`.py` files for leaked secrets.
- `[audit_iso29119.py:ROOT]`, `[audit_iso29119.py:evaluate_testing]`, `[audit_iso29119.py:main]` — ISO/IEC/IEEE 29119 audit checking C/Python test counts, `Makefile` test targets, and CI workflow presence.
- `[audit_iso9001_31000.py:ROOT]`, `[audit_iso9001_31000.py:REQUIRED_DOCS]`, `[audit_iso9001_31000.py:evaluate_qms_and_risk]`, `[audit_iso9001_31000.py:main]` — ISO 9001 & 31000 audit checking 9 required `docs/*.md` files and `Makefile` quality gates.
- `[check_traceability.py:ROOT]`, `[check_traceability.py:check_shader_spv_pairing]`, `[check_traceability.py:check_c_header_and_tests]`, `[check_traceability.py:main]` — ISO/IEC 29110-SI & 12207 verifier checking `.vert`/`.frag` -> `.spv` freshness and C module header/test coverage.
- `[estimate_cocomo_fp.py:ROOT]`, `[estimate_cocomo_fp.py:THIRD_PARTY]`, `[estimate_cocomo_fp.py:NOMINAL_SCALE_FACTORS]`, `[estimate_cocomo_fp.py:IFPUG_WEIGHTS]`, `[estimate_cocomo_fp.py:IFPUG_CATALOG]`, `[estimate_cocomo_fp.py:COSMIC_PROCESSES]`, `[estimate_cocomo_fp.py:count_sloc_file]`, `[estimate_cocomo_fp.py:collect_project_sloc]`, `[estimate_cocomo_fp.py:summarize_ifpug_catalog]`, `[estimate_cocomo_fp.py:compute_ifpug_ufp]`, `[estimate_cocomo_fp.py:compute_cosmic_cfp]`, `[estimate_cocomo_fp.py:compute_cocomo_ii]`, `[estimate_cocomo_fp.py:main]` — SLOC counter, IFPUG UFP & COSMIC CFP calculator, and COCOMO-II Post-Architecture estimator.

## Invariants

- `[evaluate_iso25040.py:classify_exit_code]`, `[evaluate_iso25040.py:main]` — Runs 8 fixed verifier scripts; maps exit code `0` to `"PASS"`, `2` to `"WARN"`, and any other code to `"FAIL"`; computes `compliance_pct = round((passed / total * 100.0) if total else 0.0, 2)` counting only `"PASS"` statuses; returns `1` iff `failed > 0` or (`--strict` and `warned > 0`), else `0`.
- `[measure_iso25023.py:check_shader_compilation]`, `[measure_iso25023.py:check_compiler_warnings]` — `Q-CMP-02` requires `glslangValidator` in `PATH`, `len(shaders) > 0`, and `errors == 0`; `Q-MNT-01` requires zero warnings (`:\d+:\d+:\s+warning:`) and zero errors compiling `src/*.c` with `gcc -Wall -Wextra -O2 -Wno-attribute-warning -Iinclude -c`; `Q-PRT-02` requires parallel compile wall time `<= 10.0s` (`workers = max(1, min(len(jobs), os.cpu_count() or 4))`).
- `[measure_iso25023.py:check_secret_leakage]`, `[measure_iso25023.py:check_glb_size]`, `[measure_iso25023.py:check_dem_topography_precision]` — `Q-SEC-01` requires `git ls-files` exit code `0` and zero matches for `AIza[0-9A-Za-z\-_]{30,}` or `sk-[0-9A-Za-z]{32,}`; `Q-PRF-03` enforces GLB size `<= 120.0` MB (returns `ok=True` if no GLB exists on disk); `Q-FNC-02` requires `max_diff < 0.05` m across 14 Aguascalientes coordinates comparing C `terrain_dem_get_elevation(x, z)` against `geo_dem.TerrainElevation(21.800, 21.950, -102.370, -102.245, nx=64, ny=64).get_real_topography(x, z)`.
- `[measure_iso25023.py:check_modular_architecture]`, `[measure_iso25023.py:check_makefile_targets]`, `[measure_iso25023.py:check_vulkan_device_extensions]`, `[measure_iso25023.py:_validate_single_glb]`, `[measure_iso25023.py:check_glb_conformance]` — `Q-MNT-02` requires `>= 8` `.c`/`.h` module pairs (excluding `cgltf.h`, `stb_image.h`); `Q-MNT-03` requires `Makefile` targets `all`, `clean`, `test`, and `metrics`; `Q-PRT-01` requires `deviceExtensions[]` in `src/vulkan_device.c` to contain only `VK_KHR_SWAPCHAIN_EXTENSION_NAME` or `"VK_KHR_swapchain"`; `Q-CMP-01` requires >=1 GLB in `models/{cars,peds}/*.glb` and every file to pass GLB v2 validation (`size >= 20`, magic `b"glTF"`, `version == 2`, `total_len == size`, JSON chunk `c0_type == b"JSON"`, `20 + c0_len <= total_len`, valid UTF-8 JSON with `asset.version` starting with `"2."`).
- `[measure_maintainability.py:analyze_c_file]`, `[measure_maintainability.py:evaluate_maintainability]`, `[measure_maintainability.py:main]` — Excludes `THIRD_PARTY` (`cgltf.h`, `stb_image.h`); skips `#`-directives at `brace_depth == 0`, strips comments/string literals, and counts McCabe complexity starting at `1 + len(BRANCH_RE.findall(...))`; flags technical debt (`has_debt`) iff any function has `cc > 20` (`cc_threshold`) or `comment_ratio < 5.0%` (`min_comment_pct`); exits `0` cleanly, `2` (`WARN`) on debt, or `1` (`FAIL`) on debt with `--strict`.
- `[validate_data_quality.py:check_traffic_signals]`, `[validate_data_quality.py:check_classified_buildings]`, `[validate_data_quality.py:check_sectors_consistency]`, `[validate_data_quality.py:check_road_network_bin]`, `[validate_data_quality.py:check_chunks_json]`, `[validate_data_quality.py:check_dem_caches]`, `[validate_data_quality.py:check_manifests]`, `[validate_data_quality.py:check_denue_csv]` — Requires `>= 99%` completeness on `traffic_signals.json` (finite `x, y, z`) and `classified_buildings.json` (`color` triple in `[0.0, 1.0]`), `100%` existence of sector GLBs in `sectors.json`, `road_network.bin` header magic `b"RGP1"` with `n_nodes > 0`, `n_edges > 0`, and byte length `16 + n_nodes * 20 + n_edges * 28 + n_points * 12`, `chunks.json` with `chunk_size > 0` and 100% valid AABBs (`count > 0`, `min <= max`), `models/dem_*.json` non-empty with `>= 99%` finite elevations in `[1000.0, 3000.0]`, non-empty `models/cars/manifest.json` with every `car_<name>.glb` and `models/peds/ped.glb` present, and `> 1` non-empty row in `denue_diccionario_de_datos.csv`.
- `[audit_iso27001_27034.py:check_security]` — Passes (exit `0`) iff `critical_findings` (`gets(`) is empty, `secret_findings` across owned `.c`/`.h` (`THIRD_PARTY_HEADERS` excluded) and `tools/**/*.py` (excluding `__pycache__`) is empty, and `Makefile` contains both `-Wall` and `-Wextra`; `ADVISORY_UNSAFE_C` (`sprintf(`, `vsprintf(`, `strcpy(`, `strcat(`) and `.gitignore` absence are informational only.
- `[audit_iso29119.py:evaluate_testing]` — Passes iff `tests/test_c_modules.c` (`>= 10` `void test_*(` functions or assertion macros fallback), `tests/test_python_tools.py` (`>= 8` `def test_*(` methods), `Makefile` targets (`test:`, `asan-test:`, `quality:`), and `.github/workflows/ci.yml` all exist.
- `[audit_iso9001_31000.py:evaluate_qms_and_risk]` — Passes iff all 9 `REQUIRED_DOCS` exist with size `> 1024` bytes and `Makefile` defines `metrics:` and `quality:`.
- `[check_traceability.py:check_shader_spv_pairing]`, `[check_traceability.py:check_c_header_and_tests]` — Passes iff `shaders/*.{vert,frag}` is non-empty with every `<base>.spv` present and `mtime(spv) >= mtime(src)`, `src/` has `>= 8` `.c` modules, and `tests/test_c_modules.c` `#include`s `>= 3` matching module `.h` headers.
- `[estimate_cocomo_fp.py:collect_project_sloc]`, `[estimate_cocomo_fp.py:compute_cocomo_ii]`, `[estimate_cocomo_fp.py:main]` — Excludes `cgltf.h` and `stb_image.h` (`THIRD_PARTY`) and `__pycache__` when counting non-blank/non-comment SLOC across `src/*.c`, `include/*.h`, `shaders/*.{vert,frag}`, and `tools/**/*.py`; applies COCOMO-II constants `a = 2.94`, `b = 0.91`, `E = b + 0.01 * sum(sf)` over static `IFPUG_CATALOG` (25 items) and `COSMIC_PROCESSES` (5 processes) plus a hardcoded `2.5` KSLOC roadmap estimate; always exits `0`.

## Side Effects

- `[evaluate_iso25040.py:main]`, `[evaluate_iso25040.py:run_step]` — Spawns the 8 metric scripts as child Python processes in `ROOT`, creates `<ROOT>/build/` (`os.makedirs(..., exist_ok=True)`), writes UTF-8 JSON to `<ROOT>/build/quality_scorecard.json`, and prints summary output to stdout.
- `[measure_iso25023.py:TOOLS_DIR]` — Mutates `sys.path` at import time by inserting `ROOT/tools` at index `0` if not present.
- `[measure_iso25023.py:check_shader_compilation]`, `[measure_iso25023.py:check_compiler_warnings]`, `[measure_iso25023.py:check_secret_leakage]`, `[measure_iso25023.py:check_dem_topography_precision]` — Creates temporary directories (`sv_spv_`, `sv_objs_`) via `tempfile.TemporaryDirectory`, invokes `glslangValidator`, parallel `gcc` processes via `ThreadPoolExecutor`, and `git ls-files`; imports `geo_dem` (instantiating `TerrainElevation` while redirecting stdout to `StringIO`), writes `/tmp/sv_dem_probe.c`, compiles and runs `/tmp/sv_dem_probe`, and removes both `/tmp` files in `finally`.
- `[validate_data_quality.py:main]`, `[audit_iso27001_27034.py:check_security]`, `[audit_iso29119.py:evaluate_testing]`, `[audit_iso9001_31000.py:evaluate_qms_and_risk]`, `[check_traceability.py:main]`, `[measure_maintainability.py:main]`, `[estimate_cocomo_fp.py:main]` — Perform read-only filesystem scans/reads across `src/`, `include/`, `shaders/`, `tools/`, `tests/`, `docs/`, `models/`, `Makefile`, `.gitignore`, and `.github/workflows/ci.yml`, and write audit reports to stdout.
